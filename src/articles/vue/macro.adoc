== コンパイラマクロ

defineProps::
+
親コンポーネントから渡される props を定義する
+
[source,vue]
----
<script setup>
// 基本的な定義
const props = defineProps({
  message: String,
  count: {
    type: Number,
    default: 0
  }
});
</script>
----
+
TypeScript の場合は型引数で型ベース定義ができる。
`?` を付けると省略可能な props になる。
+
[source,vue]
----
<script setup lang="ts">
const props = defineProps<{
  message: string,
  count?: number
}>();
</script>
----
+
`interface` に切り出してもよい。デフォルト値は後述の `withDefaults` で設定する。
+
[source,vue]
----
<script setup lang="ts">
interface Props {
  message: string;
  count?: number;
}

const props = defineProps<Props>();
</script>
----

defineEmits::
+
親コンポーネントに対してイベントを発行(emit)するために許可するイベント名を定義する。
+
[source,vue]
----
<script setup>
const emit = defineEmits(['updateCount', 'submitForm']);

function handleClick() {
  emit('updateCount', 1);
}
</script>
----
+
TypeScript の場合は型引数でイベント名と引数の型を定義する。
+
[source,vue]
----
<script setup lang="ts">
// 呼び出しシグネチャ形式
const emit = defineEmits<{
  (e: 'updateCount', value: number): void;
  (e: 'submitForm'): void;
}>();

// 名前付きタプル形式 (Vue 3.3+)。こちらの方が簡潔
const emit2 = defineEmits<{
  updateCount: [value: number];
  submitForm: [];
}>();
</script>
----

defineExpose::
+
`script setup` を使うとコンポーネントはデフォルトで閉じられ(プライベートに)なる。
このマクロは、親コンポーネントが ref を介してアクセスできるプロパティやメソッドを **明示的に公開(expose)** する。
+
[source,vue]
----
<script setup>
import { ref } from 'vue';

const internalValue = ref(0);

// openModalメソッドだけを親から呼び出せるように公開する
defineExpose({
  openModal: () => {
    internalValue.value = 100;
  }
});
</script>
----
+
TypeScript の場合、`defineExpose` 自体には型引数を渡さない。
公開した内容は引数のオブジェクトから推論される。
親側では `InstanceType` で子コンポーネントのインスタンス型を取得して ref に指定する。
+
[source,vue]
----
<!-- 子コンポーネント (Modal.vue) -->
<script setup lang="ts">
import { ref } from 'vue';

const internalValue = ref(0);

defineExpose({
  openModal: (): void => {
    internalValue.value = 100;
  }
});
</script>

<!-- 親コンポーネント -->
<script setup lang="ts">
import { ref } from 'vue';
import Modal from './Modal.vue';

const modal = ref<InstanceType<typeof Modal> | null>(null);

function open() {
  modal.value?.openModal();
}
</script>

<template>
  <Modal ref="modal" />
</template>
----

defineModel (Vue 3.4+)::
+
コンポーネントで v-model を使うための双方向バインディングを非常に簡単に実装できるようにするマクロ。
以前の props と emits を組み合わせた実装の簡素化版。
+
[source,vue]
----
<script setup>
// 'modelValue' という名前の v-model を定義する
const model = defineModel();

// 'count' という名前の v-model を定義する (例: v-model:count)
const count = defineModel('count');

function update() {
  model.value = 'new value'; // 親コンポーネントの値も更新される
}
</script>
----
+
TypeScript の場合は型引数で値の型を指定する。
名前付きの場合は第1引数に名前、第2引数にオプション (`default` や `required`) を指定できる。
+
[source,vue]
----
<script setup lang="ts">
// Ref<string | undefined>
const model = defineModel<string>();

// Ref<string> (required を付けると undefined を含まない)
const title = defineModel<string>('title', { required: true });

// Ref<number> (default があれば undefined を含まない)
const count = defineModel<number>('count', { default: 0 });
</script>
----

defineOptions (Vue 3.3+)::
+
`<script setup>` を使いながらも name(コンポーネント名) や inheritAttrs など、従来の Options API でしか設定できなかったコンポーネントのオプションを定義できるようにするマクロ。
+
[source,vue]
----
<script setup>
defineOptions({
  name: 'MyCustomButton',
  inheritAttrs: false // ルート要素に属性を自動継承しない
});
</script>
----
+
TypeScript の場合も書き方は同じ。`lang="ts"` を付けるだけでよい。
+
[source,vue]
----
<script setup lang="ts">
defineOptions({
  name: 'MyCustomButton',
  inheritAttrs: false
});
</script>
----

withDefaults::
+
defineProps で TypeScript の型ベース定義を使う際に props のデフォルト値を設定するためのヘルパーマクロ。
TypeScript 専用 (`lang="ts"` が必要)。
+
[source,vue]
----
<script setup lang="ts">
interface Props {
  message: string;
  delay?: number;
}

const props = withDefaults(defineProps<Props>(), {
  message: 'Hello',
  delay: 200 // デフォルト値を設定
});
</script>
----
+
Vue 3.5+ では、props の分割代入でデフォルト値を書く方法でも同じことができる (リアクティビティも維持される)。
+
[source,vue]
----
<script setup lang="ts">
const { message = 'Hello', delay = 200 } = defineProps<{
  message?: string;
  delay?: number;
}>();
</script>
----

defineSlots (主にTypeScript用)::
+
コンポーネントが受け入れるスロットとその props の型を定義する。
これによりスロット利用時の型チェックが強化される。
JavaScript では型を定義できないため、TypeScript での利用が前提となる。
+
[source,vue]
----
<script setup lang="ts">
// スロットの型を定義
defineSlots<{
  default(props: { item: string }): any;
  header(): any;
}>();
</script>
----

ref によるリアクティブな変数について::
* script 内で参照する場合は `.value` が必要
* template 内で参照する場合は自動的にアンパックするので value は不要
