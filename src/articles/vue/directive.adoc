== ディレクティブ

`v-` で始まる特別な属性。テンプレート内で DOM の描画や挙動をリアクティブに制御する。

=== 一覧と省略形

[cols="2,1,3",options="header"]
|===
|ディレクティブ |省略形 |用途

|`v-bind`
|`:`
|属性や props に式の値をバインドする

|`v-on`
|`@`
|イベントリスナーを登録する

|`v-slot`
|`#`
|名前付きスロットやスコープ付きスロットを受け取る

|`v-model`
|なし
|フォーム要素やコンポーネントとの双方向バインディング

|`v-if` / `v-else-if` / `v-else`
|なし
|条件付きレンダリング (要素ごと生成・破棄する)

|`v-show`
|なし
|`display` の切り替えによる表示・非表示

|`v-for`
|なし
|リストレンダリング

|`v-text` / `v-html`
|なし
|テキスト / HTML として内容を差し込む

|`v-once` / `v-memo`
|なし
|再レンダリングの抑制

|`v-pre` / `v-cloak`
|なし
|コンパイルのスキップ / コンパイル完了までの非表示
|===

=== v-bind (`:`)

属性や props に式の値をバインドする。

[source,vue]
----
<template>
  <!-- 通常記法 -->
  <img v-bind:src="imageUrl" v-bind:alt="altText">

  <!-- 省略形 -->
  <img :src="imageUrl" :alt="altText">

  <!-- 属性名と変数名が同じ場合の省略 (Vue 3.4+) -->
  <img :src :alt="altText">

  <!-- class / style はオブジェクトや配列で指定できる -->
  <div :class="{ active: isActive }" :style="{ color: textColor }"></div>

  <!-- オブジェクトで複数まとめてバインド -->
  <MyComponent v-bind="props" />

  <!-- 動的な属性名 -->
  <a :[attrName]="url">link</a>
</template>
----

=== v-on (`@`)

イベントリスナーを登録する。

[source,vue]
----
<template>
  <!-- 通常記法 -->
  <button v-on:click="increment">+1</button>

  <!-- 省略形 -->
  <button @click="increment">+1</button>

  <!-- インラインで式を書く -->
  <button @click="count++">+1</button>

  <!-- 修飾子 -->
  <form @submit.prevent="onSubmit">...</form>
  <button @click.once="onlyOnce">once</button>
  <input @keyup.enter="submit">
</template>
----

主な修飾子::
* `.stop` : `event.stopPropagation()` を呼ぶ
* `.prevent` : `event.preventDefault()` を呼ぶ
* `.once` : 1回だけ実行する
* `.self` : 要素自身が発生源のときだけ実行する
* `.capture` : キャプチャモードで登録する
* `.enter` `.esc` など : 押されたキーを限定する

=== v-model

双方向バインディング。`<input>` などのフォーム要素や、コンポーネントに使う。
省略形は無い。

[source,vue]
----
<script setup>
import { ref } from 'vue';

const text = ref('');
const checked = ref(false);
</script>

<template>
  <input v-model="text">
  <input type="checkbox" v-model="checked">

  <!-- 修飾子 -->
  <input v-model.trim="text">
  <input v-model.number="age">
  <input v-model.lazy="text"> <!-- change イベントで同期 -->

  <!-- コンポーネントでの利用 (子側は defineModel で受ける) -->
  <MyInput v-model="text" />
  <MyInput v-model:title="title" />
</template>
----

=== v-if / v-else-if / v-else

条件に応じて要素を生成・破棄する。
切り替えコストが高い代わりに、非表示のときの初期描画コストは低い。

[source,vue]
----
<template>
  <p v-if="score >= 80">良</p>
  <p v-else-if="score >= 50">可</p>
  <p v-else>不可</p>

  <!-- 複数要素をまとめて切り替えるときは template を使う -->
  <template v-if="isLoggedIn">
    <h1>Welcome</h1>
    <p>...</p>
  </template>
</template>
----

=== v-show

`display: none` の切り替えで表示・非表示を制御する。
要素は常に生成されるため、頻繁に切り替える場合に向いている。
`<template>` 要素には使えず、`v-else` とも組み合わせられない。

[source,vue]
----
<template>
  <p v-show="isVisible">表示されるとき</p>
</template>
----

=== v-for

配列・オブジェクト・数値などを繰り返し描画する。
`:key` を必ず指定する。

[source,vue]
----
<template>
  <!-- 配列 -->
  <li v-for="item in items" :key="item.id">{{ item.name }}</li>

  <!-- インデックス付き -->
  <li v-for="(item, index) in items" :key="item.id">{{ index }}: {{ item.name }}</li>

  <!-- オブジェクト (値, キー, インデックス) -->
  <li v-for="(value, key, index) in obj" :key="key">{{ key }}: {{ value }}</li>

  <!-- 数値 (1 から 10) -->
  <span v-for="n in 10" :key="n">{{ n }}</span>
</template>
----

NOTE: 同じ要素に `v-if` と `v-for` を併用した場合、Vue 3 では `v-if` が先に評価される。
併用は避け、`computed` で絞り込むか `<template v-for>` を使う。

=== v-slot (`#`)

名前付きスロットや、スロットの props を受け取る。
子コンポーネント側の `<slot>` に対して、親側で内容を渡す。

[source,vue]
----
<template>
  <!-- 通常記法 -->
  <BaseLayout>
    <template v-slot:header>ヘッダー</template>
  </BaseLayout>

  <!-- 省略形 -->
  <BaseLayout>
    <template #header>ヘッダー</template>

    <!-- スコープ付きスロット (子から渡された props を受け取る) -->
    <template #default="{ item }">{{ item }}</template>
  </BaseLayout>
</template>
----

=== その他

v-text / v-html::
`v-text` は `textContent` を、`v-html` は `innerHTML` を設定する。
`v-html` は XSS の危険があるため、信頼できる内容にだけ使う。
+
[source,vue]
----
<span v-text="msg"></span>
<!-- 上と同じ -->
<span>{{ msg }}</span>

<div v-html="rawHtml"></div>
----

v-once::
一度だけ描画し、以降の更新を無視する。

v-memo (Vue 3.2+)::
指定した値の配列が変化しない限り、要素のサブツリーの更新をスキップする。主に大きなリストの最適化に使う。
+
[source,vue]
----
<div v-for="item in list" :key="item.id" v-memo="[item.id === selected]">
  ...
</div>
----

v-pre::
その要素と子要素のコンパイルをスキップし、`{{ }}` をそのまま表示する。

v-cloak::
コンパイル完了まで要素を隠すために使う (CDN 版など、ビルドなしで使う場合向け)。
+
[source,html]
----
<style>
[v-cloak] { display: none; }
</style>
<div v-cloak>{{ message }}</div>
----
